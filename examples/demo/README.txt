НАБОР ПРИМЕРОВ TEXTMASK

Все данные синтетические. Не используйте телефон для связи.
В файлах 01–07 один и тот же текст на русском языке.

ФАЙЛЫ ДЛЯ ОТКРЫТИЯ
01-sample.txt — обычный текст UTF-8.
02-sample.md — тот же текст в Markdown.
03-sample.docx — документ Word с текстовыми абзацами.
04-text.pdf — PDF с доступным текстовым слоем.
05-scan.pdf — PDF из изображения без текстового слоя, запускает OCR.
06-scan.png и 07-scan.jpg — изображения для OCR.

ПРОВЕРКА 1
Откройте TextMask и нажмите «Очистить».
Оставьте включёнными Email и Телефоны РФ.
Выключите Ссылки и IPv4, очистите дополнительные замены.
Откройте один из файлов 01–07. Дождитесь завершения чтения.
Нажмите «Маскировать».
Ожидается 4 замены: email 2, телефоны 2; уникальных меток 2.
Для TXT/MD точный результат — expected/01-basic.txt.

ПРОВЕРКА 2
Включите все четыре переключателя.
Раскройте «Дополнительные замены» и вставьте две строки из manual-rules.txt.
Нажмите «Маскировать».
Ожидается 12 замен: email 2, телефоны 2, ссылки 2, IPv4 2, строки 4.
Уникальных меток 6. Для TXT/MD результат — expected/02-all.txt.
В «Проверить замены» отображаются 6 меток, у каждой по два вхождения.
Нажатие на метку показывает исходный фрагмент, стрелки переходят по 12 заменам.
Нажмите «Скачать TXT» и проверьте сохранённый обработанный текст.

ДЛЯ PDF И СКАНОВ
Переносы и пустые строки могут отличаться от TXT. Сравнивайте значения и метки.
OCR может ошибаться: до маскирования проверьте email, телефоны, ссылки и имя.
Для 05-scan.pdf, PNG и JPEG OCR включается автоматически.
Для принудительного OCR файла 04-text.pdf сначала включите переключатель
«OCR всех страниц PDF» в «Форматы и OCR», затем заново откройте файл.
Этот набор проверяет обычный сценарий, а не полное обезличивание любых документов.
