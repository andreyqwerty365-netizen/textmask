# Сборка Windows portable

## Требования

Windows x64, Windows PowerShell 5.1 или PowerShell 7, .NET Framework 4.8 со штатным `csc.exe`, Node.js 24 для тестов. Установка npm/NuGet-пакетов не нужна. Интернет требуется только для получения официального архива Node.js при первой сборке.

```powershell
npm test
npm run check
npm run build:windows
```

Архив: `dist/TextMask-2.0.0-windows-x64.zip`. Временная папка сборки создаётся внутри `dist/` и удаляется после проверки её пути. Runtime скачивается один раз, SHA-256 проверяется при каждой сборке. Повреждённый архив отклоняется до извлечения.

Для сборки из заранее скачанного архива:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-windows.ps1 -NodeArchive C:\Downloads\node-v24.22.1-win-x64.zip
```

Версия и закреплённый хеш находятся в сценарии. Источники и условия распространения — [THIRD_PARTY.md](../THIRD_PARTY.md). При смене версии согласованно обновите package.json, метаданные Launcher.cs, manifest и инструкцию.

## Содержимое ZIP

```text
TextMask-2.0.0-windows-x64/
  TextMask.exe          # Windows Forms launcher, исходник packaging/Launcher.cs
  START-HERE.txt        # инструкция пользователя
  BUILD.json           # версия и происхождение runtime
  FILES.sha256         # SHA-256 всех остальных файлов папки
  LICENSE              # MIT приложения
  app/                 # статические файлы, локальные библиотеки и сервер
  runtime/node.exe     # официальный неизменённый Node.js x64
  runtime/LICENSE      # полные уведомления Node.js и его компонентов
  examples/demo/       # синтетические документы, правила и ожидаемые TXT
```

EXE использует абсолютный путь к соседнему runtime; установленный Node.js и PATH не нужны. `NODE_OPTIONS` и `NODE_PATH` не наследуются дочерним runtime. Каталоги с пробелами и кириллицей поддерживаются.

Оболочка держит именованный mutex и сигналы открытия/остановки в текущем сеансе Windows. Дочерний сервер сообщает о готовности через stdout; его stdin привязан к оболочке. Остановка или аварийное завершение оболочки закрывает канал и сервер. HTTP-маршрутов администрирования, пользовательских журналов, файлов состояния и изменения реестра нет.

Сервер слушает только `127.0.0.1:4175`. Если порт занят посторонним процессом, EXE выводит инструкцию и завершается. Никакие чужие процессы не завершаются. Закрытие браузера не останавливает сервер — для этого есть меню значка в трее.

В архив не входят Git, node_modules, npm, компилятор, тестовые журналы и пользовательские документы. EXE не подписан; подпись издателя и установщик — отдельные возможные доработки. Сборка повторяема из открытых исходников и закреплённого runtime; байтовая идентичность ZIP не обещается из-за времени файлов и метаданных компилятора.

## Приёмка архива

Распакуйте ZIP в отдельную папку, остановите свой прежний TextMask и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-windows.ps1 -PackageRoot "C:\Tests\TextMask-2.0.0-windows-x64"
```

Сценарий проверяет реальный EXE, собственный runtime, цикл запуска/остановки, повторный запуск, loopback, освобождение порта после сбоя и занятый чужим процессом порт. Он отказывается начинать, если порт уже занят. `--background` отключает открытие браузера и диалоги для автоматизации, сохраняя сервер и значок в трее. Обычный запуск без параметров открывает браузер.

Проверка документов в браузере описана в [TESTING.md](TESTING.md). CI проверяет исходники на Ubuntu/Windows и собирает/проверяет portable ZIP на Windows.
