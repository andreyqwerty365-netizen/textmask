# Идеи вне первой версии

Не реализованы; не расширяют согласованный объём:

- Исследовать поддержку Unicode email и редких телефонных форматов с отдельным набором примеров.
- Набор проверок в Firefox и Safari на реальных устройствах.
- Сохранение оформления и экспорт обработанных DOCX/PDF вместо TXT.
- Дополнительные типы идентификаторов — только с отдельно определёнными правилами и проверками; автоматического поиска имён/адресов пока нет.

С 23.10.2026 локальные TXT/MD, DOCX, PDF, сканы PNG/JPEG, OCR rus/eng и экспорт TXT реализованы по запросу пользователя. Загрузка документов на сервер, история и внешние API не входят в текущую версию.

Следующим поручением реализованы перетаскивание, этапы/страницы OCR, переключатели правил и новые типы URL/IPv4, проверка замен и мобильные улучшения. Это завершённый объём, а не пункты backlog.
