# Проверки TextMask

Нужен Node.js 24+. Из корня: `npm test` (31 тест), `npm run check` (синтаксис). Сторонние пакеты не нужны.

| Область | Покрытие |
| --- | --- |
| Распознавание | Email с апострофом/плюсом, регистр, распространённые российские телефоны, неподдерживаемые и неполные значения |
| Замены | Стабильные повторы, точные литералы с regexp-символами, пробелы, пересечения цепочкой/мостом, резервирование существующих меток |
| Ввод | Пустота, отсутствие совпадений, типы, ограничения длины/правил/числа кандидатов |
| Контроллер | Пример не затирает ввод и пробельные строки; изменение очищает устаревший результат; клавиатурная ссылка и Ctrl+Enter восстанавливают нужный фокус |
| HTTP | Allowlist, CSP/connect-src none, no-store, HEAD, запрет POST и внутренних файлов |

Контроллерные тесты исполняют реальный app.js и maskText с минимальной DOM-границей. Они не заменяют настоящий браузер для фокуса, вёрстки и буфера обмена.

## Браузерная приёмка — 22 октября 2026

Edge 155 / Chromium на Windows: исходник и результат, 6 замен и 4 уникальные метки в примере; email разных регистров, телефон в нескольких форматах, точные строки, пересечения и повторные совпадения. HTML остаётся текстом. Проверены пустота, лимиты и отсутствие совпадений.

После изменения исходника или правил копирование старого результата недоступно. Проверены Clipboard API, отказ с выделением и ручным Ctrl+C, очистка, reload и возврат назад без восстановления текста. Ввод не появляется в localStorage/sessionStorage/URL; запросы приложения ограничены собственными статическими ресурсами.

Tab/Enter, Ctrl+Enter, skip-link, стрелки/Home/End на вкладках; ширины 320, 390, 768 и 1440 px, touch-эмуляция, раскрытые правила/справка и сообщение об ошибке. Непредусмотренного горизонтального переполнения и ошибок консоли в проверенных сценариях не обнаружено.

## Ограничения приёмки

Firefox, Safari, физические iOS/Android, screen reader и полная WCAG-проверка не выполнялись. Локальные тесты не доказывают распознавание любых персональных данных. Имена, адреса, документы и редкие форматы требуют ручной проверки.

GitHub Actions запускает npm test на Node.js 24 в Ubuntu и Windows. Браузерная приёмка описана отдельно и не выдаётся за часть CI.
