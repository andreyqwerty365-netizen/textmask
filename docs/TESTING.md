# Проверки TextMask 2.0

## Автоматические проверки

```sh
npm test
npm run check
```

49 проверок `node:test`: правила и пересечения, идентичность меток, ограничения, чтение файлов, состояния интерфейса, разрешённые HTTP-ресурсы и жизненный цикл portable-сервера. Сторонние тестовые библиотеки не требуются. CI запускает их на Node.js 24 в Ubuntu и Windows.

Оболочка Windows отдельно проверяется сценарием [test-windows.ps1](../scripts/test-windows.ps1), после [сборки](BUILD.md). 10 проверок: loopback, запуск, повторное использование экземпляра, остановка/перезапуск, завершение после сбоя оболочки и обработка занятого порта без остановки его владельца.

## Браузерная приёмка

Необязательный runner использует отдельно предоставленный Playwright и Edge/Chrome; он не входит в сборку пользователя и не добавлен в зависимости проекта. На компьютере с доступным Playwright:

```powershell
# Сначала запустите TextMask из исходников или распакованного ZIP.
$env:TEXTMASK_PLAYWRIGHT_PATH = 'C:\path\to\node_modules\playwright'
$env:TEXTMASK_BROWSER = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
# Можно указать примеры именно из распакованного архива:
$env:TEXTMASK_EXAMPLES = 'C:\Tests\TextMask-2.0.0-windows-x64\examples\demo'
node scripts/browser-acceptance.cjs
```

Runner проверяет все семь примеров: ввод, кириллицу, обе подписи IPv4, базовые 4 замены / 2 метки, все правила 12 замен / 6 меток, отсутствие исходных значений в результате, фактический скачанный TXT, неизменность оригинала, отсутствие внешних запросов и ошибок. На мобильном viewport 390×844 проверяет доступность кнопки экспорта и переполнение. Снимки desktop/mobile и JSON-результат сохраняются в игнорируемую `work/browser/`.

## Проверка вручную

1. Откройте каждый файл из `examples/demo`, проверьте распознанный текст.
2. С настройками по умолчанию получите 4 замены / 2 метки.
3. Включите URL и IPv4, добавьте строки из `manual-rules.txt`: 12 замен / 6 меток.
4. Пройдите по повторам, скачайте TXT и сравните с результатом редактора. Эталонные TXT предназначены для исходного текста; разбиение строк извлечённого PDF/OCR может отличаться.
5. Измените исходник: старый экспорт должен заблокироваться. Перезагрузите страницу: поля должны очиститься.
6. Остановите TextMask через трей, повторно запустите EXE; проверьте, что прежний ввод не восстановился.
