# TextMask 2.0 — документы, сканы и удобный запуск

Теперь можно подготовить к передаче в ИИ не только вставленный текст, но и документ или скан. TextMask извлекает текст, помогает скрыть поддерживаемые контакты и выбранные строки, показывает замены и сохраняет результат в TXT. Всё выполняется на вашем компьютере.

## Скачать и запустить

Скачайте **TextMask-2.0.0-windows-x64.zip** ниже, распакуйте **весь архив** и откройте **TextMask.exe**. Браузер откроется автоматически. Node.js, терминал, установка и интернет при работе не нужны.

Оболочка предназначена для Windows 10/11 x64 с .NET Framework 4.8. Рекомендуется Edge или Chrome; сборка проверена на Windows 11 x64. В трее есть команды открытия интерфейса и **«Остановить и выйти»**. Повторный запуск использует уже работающий экземпляр. Закрытие вкладки очищает текст, но сервер останавливается через трей.

EXE не подписан сертификатом издателя: Windows может показать предупреждение. Контрольные суммы файлов релиза находятся в **SHA256SUMS.txt**. Внутри ZIP есть инструкция, лицензии, сведения о runtime и хеши всех файлов. Не отделяйте EXE от папок приложения.

## Что добавлено

- **Документы:** TXT/MD, DOCX, PDF с текстом, PDF-сканы, PNG и JPEG. Результат — обработанный UTF-8 TXT с именем исходного файла. Оригинал остаётся нетронутым.
- **Распознавание:** локальное русское и английское OCR, автоматическое определение сканированных страниц PDF и возможность принудительного OCR. Показаны этап, текущая страница и реальный прогресс; операцию можно отменить.
- **Правила:** переключатели email, российских телефонов, URL и IPv4 плюс точные строки вручную. Повторы связываются одной меткой, пересекающиеся фрагменты скрываются целиком.
- **Проверка:** список уникальных меток с числом повторов, переходы по вхождениям и страницы по 20 меток. Изменение исходника или правил блокирует старый экспорт.
- **Мобильный интерфейс:** компактные поля и отступы, внутренний скролл длинного текста, основные кнопки рядом с редактором.
- **Исправление OCR:** обе подписи IPv4 на контрольных PDF-скане и PNG распознаются правильно благодаря словарным подсказкам.
- **Поставка:** EXE с собственным Node.js, открытые исходники оболочки и сборки, семь синтетических примеров с ожидаемыми результатами, обновлённые инструкции и скриншоты.

## Проверено и ограничения

Перед публикацией пройдены 49 проверок логики/HTTP, проверка синтаксиса, 10 проверок реального Windows EXE и браузерная приёмка всех семи форматов. Для PDF-скана и PNG отдельно повторены русское OCR, исправленные подписи IPv4, маскирование и чтение реально скачанного TXT на мобильном viewport. Проверены собственный runtime без системного Node.js, остановка/перезапуск и занятый порт. Мобильная проверка выполнена в эмуляции Edge/Chromium.

Один файл до **20 МиБ**, PDF до **30 страниц**, текст до **100 000 символов**. Результат всегда TXT: оформление и изображения не сохраняются. Старые `.doc`, защищённые PDF и пакетная обработка не поддерживаются. OCR может ошибаться; имена, адреса и произвольные секреты требуют ручных правил и проверки результата. Это помощник для маскирования, а не гарантия полного обезличивания.

Документы не отправляются в облако или локальный сервер. Нет аналитики, истории и внешних API; сервер доступен только на `127.0.0.1:4175`. Linux/macOS могут запускать исходники через Node.js; готовая оболочка в этом релизе — Windows x64.
